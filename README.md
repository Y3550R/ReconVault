# ReconVault

A simple **network reconnaissance asset management system** designed for offensive security work; features included but not limited to initializing a network scope, adding/removing host systems, host port and service scanning, and service vulnerability finding

This is simply created as a course project for a Database Programming Lab. Thus, I do not recommend it for real world use case but more to learn and understand how databases can be integrated with active reconnaissance. Since the project is done, I'm not really gonna continue it and will keep the repository archived.
